# 架构决策记录（ADR）

这里记录**真正的分叉**——代码往一个方向走了、而某处文档还写着另一个方向，
或者有一个只有项目所有者能拍板的取舍。

为什么用这个机制：一个写着「状态：未决」的 ADR 是**可见的**，而一个缺席的决策是隐形的。
在此之前，`CLAUDE.md` 在小红书抓取这件事上写的话和代码完全相反，而 `CLAUDE.md`
恰恰是下一个 AI agent（和三个月后的你）会相信的那一份。

## 规则

- 代码里反转了某个决策，**必须**同步反转它的 ADR。
- 每条事实只在一个地方断言，其余地方链接过去。
- 决定之后把状态从「未决 ⚠️」改成「已决」，并写上日期和理由。
